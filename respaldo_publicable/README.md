# Respaldo publicable del bot

Copias de los archivos de configuración, estados, sesiones, registros actuales e históricos y el ZIP del código. Las credenciales, tokens, identificadores de acceso y datos de autenticación se sustituyeron por `[OCULTO]`. Los originales permanecen locales.

Captura puntual: los archivos no se actualizan automáticamente. Este respaldo conserva datos de operaciones y resultados; el bot informa modo PAPER. No incluye el entorno virtual de dependencias, cachés, archivos de macOS ni bloqueos de ejecución.
